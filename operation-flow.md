# Operation Flow

![](<.gitbook/assets/image (25)>)

Here's an improved, step-by-step guide to using Ticket Contracts for a seamless trading experience:

{% stepper %}
{% step %}
### Choose leverage and entry fee

* View the dynamic leverage based on timing (e.g., lower at the start such as 100x, increasing near expiration up to 6000x+).
* The entry fee is auto-calculated (example formula provided in UI):\
  Entry Fee = Asset Price ÷ Leverage
{% endstep %}

{% step %}
### Place order and enter cycle

* Confirm the order to lock in your entry price via the multi-source aggregated system.
* The 10-minute cycle begins immediately upon order confirmation.
{% endstep %}

{% step %}
### Monitor and manage position

* Track real-time price fluctuations.
* You can manually close early to lock in profits or cut losses, or hold the position until auto-settlement at expiration.
{% endstep %}

{% step %}
### Settlement and payout

* Profits are calculated from the price difference, trade direction, and position size.
* A 10% settlement fee is deducted from profits (if any).
* Returns are received instantly after settlement.
{% endstep %}
{% endstepper %}

This flow ensures simplicity, transparency, and control, with 24/7 availability for non-stop trading 🌐.
