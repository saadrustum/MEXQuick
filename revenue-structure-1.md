# Revenue Structure

![Revenue Model](<.gitbook/assets/image (69)>)

* Profit split: 90% fixed return · 10% fee (50% off when paying with MQT)
* Correct prediction: Receive investment amount + (investment amount × 90% fixed return)
* Wrong prediction: Lose the entire investment amount
* Handling fee: Fixed 10%; 50% discount applies if paid with MQT

{% hint style="info" %}
Paying fees with MQT grants a 50% discount on the handling fee.
{% endhint %}
