# Path to Listing

{% stepper %}
{% step %}
### Phase 1: DEX Launch (Self-Built Liquidity) 💧

[Direct link to heading](path-to-listing.md#phase-1-dex-launch-self-built-liquidity)

* Listing on mainstream decentralized exchanges such as **PancakeSwap** and **Uniswap**
* Opening the **MQT/USDT trading pair** and configuring initial liquidity
* Combining **"market-making pool + liquidity mining incentives"** to ensure users can buy and sell freely from the start
* **Function:** Transparency, openness, and enhancing community trust
{% endstep %}

{% step %}
### Phase 2: Listing on Medium-Sized CEXs (Expanding Coverage) 🌍

[Direct link to heading](path-to-listing.md#phase-2-listing-on-medium-sized-cexs-expanding-coverage)

* Listing on medium-sized exchanges such as **MEXC**, **Gate.io**, **KuCoin**, and **BitMart**
* Leveraging the user base and marketing promotion of exchanges to enhance the **global visibility** of MQT
* Integrating market activities such as **airdrops**, **proxy rewards**, and **trading competitions** to expand the community scale
{% endstep %}

{% step %}
### Phase 3: Listing on Top CEXs (Mainstream Recognition) 🏆

[Direct link to heading](path-to-listing.md#phase-3-listing-on-top-cexs-mainstream-recognition)

* Promote cooperation with top exchanges such as **Binance**, **OKX**, **Bybit**, and **Huobi**
* Combine **regulatory compliance qualifications** (e.g., US MSB, Singapore/Hong Kong licenses) to meet first-tier listing standards
* **Significance:** Promote MQT to the **global mainstream market**, forming a **transnational user base** and **secondary market trust**
{% endstep %}

{% step %}
### Eco-Integration (Parallel Advancement) 🔗

[Direct link to heading](path-to-listing.md#eco-integration-parallel-advancement)

> This is not strictly "Phase 4" but progresses in parallel with — or ahead of — the listing plan.

* Implement more **MQT usage scenarios** within the **MEXQuick ecosystem**, including:
  * Transaction fee deduction ( **50% discount**)
  * **UID Market:** P2P trading, NFT, and equity card circulation
  * **Guild System:** Governance and profit distribution
  * **NFT Battles**, **GameFi**, **RWA**, and other expanded scenarios
* **Significance:** Before external exchanges are fully covered, establish **endogenous usage demand** to enhance the **intrinsic value support** of MQT.
{% endstep %}
{% endstepper %}

The phased expansion — from decentralized liquidity to global CEX listings and internal ecosystem integration — ensures MQT’s long-term sustainability, liquidity depth, and community-driven growth.
